How 4d6 drop lowest works

Roll four six-sided dice, ignore the lowest and add up the other three. Do that six times and you have six scores from 3 to 18 to assign to Strength, Dexterity, Constitution, Intelligence, Wisdom and Charisma however you like. It’s one of the three methods in both the 2014 and 2024 Player’s Handbooks, beside the standard array and point buy. Your racial (2014) or background (2024) bonuses go on afterwards, as with any method.

Dropping the lowest die pushes the results up: a single 4d6-drop-lowest score averages 12.24, against 10.5 for plain 3d6. Rolling a 1 hurts less, because it’s usually the die you drop.

What a rolled set is worth in point buy

Point buy only prices scores from 8 to 15, so to compare a rolled set this tool extends the cost table the way many groups do: 16 costs 12, 17 costs 15 and 18 costs 19, and scores under 8 give points back (7 is −1, 6 is −2, 5 is −4, 4 is −6, 3 is −9). It isn’t an official rule, just a yardstick: point buy gives everyone 27 points, and an average 4d6-drop-lowest set is worth about 31.4.

Common questions

What’s the average of 4d6 drop lowest?

12.24 per score (exactly 15,869 ÷ 1,296), so about 73.5 for a set of six. Plain 3d6 averages 10.5.

Is rolling better than point buy?

On average, slightly: a rolled set is worth about 31 points against point buy’s 27. But 34% of sets come out worse than point buy, and the spread between players at the same table can be large. Many groups roll for fun and allow point buy for anyone unhappy with the result.

What should I do if my rolls are terrible?

Ask your DM. Common table rules let you reroll a set whose modifiers add up to +0 or less, or whose highest score is below 14, or let you take the standard array instead.

Can I rearrange the scores after rolling?

Yes. In 5e you roll six scores and assign them to the abilities you want. Rolling “in order” (the first score is Strength, and so on) is an old-school variant, not the default.

Does 2024 D&D still use 4d6 drop lowest?

Yes. The 2024 Player’s Handbook keeps random generation (4d6, drop the lowest) as an option beside the standard array and point buy.

Are these rolls random?

Yes. Each die uses the browser’s cryptographic random number generator, with rejection sampling so every face is equally likely.
